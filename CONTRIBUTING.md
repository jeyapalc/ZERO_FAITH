# Contributing

Edit canonical JSON. Require exact primary-source links, an original concise annotation, scope, context, evidence basis, and research date. Attribute research classifications and distinguish them from legal designation. Distinguish project query phrases and translations from documented labels.

Canadian source IDs are language-scoped; English/French IDs cannot join translations. Preserve unsplit aliases rather than inventing name equivalence. Refresh the live register before relying on status. Do not add protected identities, ordinary religious terms, peaceful advocacy, speculative codes, operational attack details, private victim material, or proprietary assessment content.

Run `python tools/build.py` and `python -m unittest discover -s tests -v`. Commit generated exports with canonical data. Review sources quarterly and after new research. Track corrections and unresolved gaps.
